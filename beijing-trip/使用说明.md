# 京秋漫游 · 北京三日旅行手册

双击 `index.html` 即可打开。无需安装依赖或启动服务器，全部使用原生 HTML、CSS、JavaScript。

- 点击 DAY 01 / 02 / 03 切换行程，也可用左右方向键切换。
- 点击景点照片查看大图；按 Esc 或关闭按钮退出。
- 地图按钮通过高德搜索地点，需要联网；请自行确认门店和入口。
- 出行清单保存在当前浏览器本地。浏览器限制存储时会提示。
- 可复制当天路线；“打印攻略”会打印三天完整行程与出行准备，可选择另存为 PDF。
- 所有景点照片在 assets 文件夹，页面离线也可浏览。照片为景点参考，非当季实时画面。

文件：index.html 页面结构，style.css 咖色新粗野主义样式，app.js 行程数据与交互，assets/ 本地图片及来源记录。download_assets.py 为可选图片下载脚本，不是运行网页的必需依赖。

路线采用原始行程；补充的中间时间为建议，餐厅与门票尚未实际预订。16:40 是银锭桥等候日落的到达计划，不是已核实的日落时刻。故宫、恭王府规则附官网链接，出行前请再次确认。

图片来源见网页底部“图片来源与行程说明”及 assets/sources.json。图片版权归来源或原作者，公开发布或商业使用前请确认授权。本项目仅保存于本机，未发布到互联网。
