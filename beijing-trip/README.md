# 京秋漫游 · 北京三日旅行手册

2026.10.30—11.01 北京三日游。咖色系新粗野主义风格，使用原生 HTML、CSS、JavaScript。

## 使用

下载或克隆仓库后，双击 `beijing-trip/index.html`。无构建步骤，无运行依赖。也可将 `beijing-trip` 设置为静态托管的发布目录。

## 功能

- 三日行程切换与地图搜索
- 10 张本地景点照片与大图查看
- 浏览器本地保存出行清单
- 复制当天行程与打印完整攻略

`assets/sources.json` 记录图片来源。照片版权归原作者或来源站点，公开传播与商业使用须确认授权。行程时间为计划，门票、餐厅与实际日落需出发前核实。

代码已上传 GitHub，不代表已经部署成网站。
